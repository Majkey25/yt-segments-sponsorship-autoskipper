## SponsorBlock

YouTube Skipper queries the public SponsorBlock API at `https://sponsor.ajay.app` for crowdsourced video segment timestamps.

- Project: https://github.com/ajayyy/SponsorBlock
- API documentation: https://wiki.sponsor.ajay.app/w/API_Docs

The client code in this repository was written independently. Data returned by the API remains subject to SponsorBlock's database and API terms.
