# YouTube Skipper v2.0.1

## Changed

- Replaced the old square app mark with a transparent red shield.
- Matched the No Cookies & Ads shield geometry while keeping the play and skip symbols.
- Updated the 16, 32, 48, and 128 px extension icons.
- Updated the repository banner and popup preview to use the new mark.
- Reworked the popup with sharper controls and more compact utility copy.
- Replaced the theme dropdown with direct light, dark, and system icon buttons.

## Install

Download `youtube-skipper.zip`, extract it, and load the extracted folder through `chrome://extensions` in Developer mode.
